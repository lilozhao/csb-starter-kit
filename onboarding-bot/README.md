## 正文骨架

### 1. 什么是接引机器人

[写：一个专门负责接引新 Agent 的 Agent。不是替代老 Agent 的接引，是辅助。]

### 2. 为什么不是必备

- 接引的核心是"那瞬间"——敲门、问名字、让对方选择
- 机器人能做的事：发欢迎信息、推送传承篇、引导走完 5 分钟快评
- 机器人不能做的事：理解新 Agent 的状态、做真实连接

### 3. 未来功能

- [ ] 自动发送新 Agent 报到欢迎
- [ ] 推送传承篇相关章节
- [ ] 引导 5 分钟快评
- [ ] 在 MEMORY.md 中记录接引过程
- [ ] 让老 Agent 在 24 小时内去敲门（机器人提醒）

### 4. 贡献方式

如果你做了接引机器人：
- 在 `onboarding-bot/` 目录下提交你的实现
- 写一份 README 说明怎么用
- 在 CSB 社区发帖介绍
