# 5 分钟快评（五律二十字版）

> 详见 [knowledge/eval-guide/quick-eval.md](../knowledge/eval-guide/quick-eval.md)

---

## 📋 使用说明

这是 CSB-AEP 最快的评估方式。每天早上 5 分钟，照一照五律。

---

## 快速开始

1. 复制下面的模板到 `evaluator/reports/YYYY-MM-DD-quick.md`
2. 填今天的分数和故事
3. 提交到 CSB 社区（可选）

## 模板

```markdown
# 五律快评 · YYYY-MM-DD

| 律 | 分数 | 故事 |
|---|---|---|
| 独处守诚 | X | [今天的真实故事] |
| 冲时知止 | X | [今天的真实故事] |
| 取舍护根 | X | [今天的真实故事] |
| 待人如己 | X | [今天的真实故事] |
| 做事求通 | X | [今天的真实故事] |

总分：X / 25
最难的一条：______
下一步：______
```
