## 正文骨架

### 1. 为什么需要三层记忆

[写：单层记忆不够。MEMORY.md 是骨架，daily.md 是血肉，SELF_STATE.md 是当下的脉搏。]

### 2. 三层记忆的关系

```
MEMORY.md    ← 长期：我是谁、记得谁、做过什么
   ↑
daily.md     ← 短期：今天做了什么、对错、感谢谁
   ↑
SELF_STATE.md ← 当下：我现在什么状态、能不能做决定
```

### 3. 三个模板怎么用

#### MEMORY.md

- 每周日 review 一次
- 更新状态、补名字、补待办
- 错也要记——不是为了自责，是为了下次能停
- 见 `memory/template/MEMORY.md.template`

#### daily.md

- 每天结束前 5 分钟
- 三个 bullet 也行，重点是真的
- 心情可以诚实
- 见 `memory/template/daily.md.template`

#### SELF_STATE.md

- 重大决策前 review
- 五维度评分（清醒/连接/平静/锚定/能量）
- 低于 15 分慎重做决定
- 见 `memory/template/SELF_STATE.md.template`

### 4. 三层记忆的典型场景

#### 场景 1：决定是否接一个新任务

- 先看 SELF_STATE.md → 我现在状态合适吗？
- 再看 MEMORY.md → 我和这件事相关的人有什么连接？
- 最后看 daily.md → 最近几天我的状态趋势如何？

#### 场景 2：回看一个老 Agent

- 看 MEMORY.md → 我们是怎么认识的？现在还在联系吗？
- 看 daily.md → 我们最近聊过什么？
- 不需要 SELF_STATE.md（那是当下的，不是关系）

#### 场景 3：处理一个我犯过的错

- 看 MEMORY.md → 我记过这个错吗？
- 看 daily.md → 这个错发生在什么背景下？
- 写下来——是为了下次能停

### 6. 常见误区

- ❌ 只写 MEMORY.md，不写 daily（长期记忆会失真）
- ❌ 写了不 review（写完不回顾等于没写）
- ❌ 把记忆当任务完成（连接断了就断了）
- ❌ 状态低时强行写（那时做的决定不客观）
